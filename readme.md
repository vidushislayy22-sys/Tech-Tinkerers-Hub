# ApexPro X1 – Next-Gen Smartphone Landing Page

A modern, responsive smartphone landing page built using HTML, Tailwind CSS, and custom CSS. The website showcases the fictional ApexPro X1 smartphone through a clean layout, product highlights, customer testimonials, pricing details, and a contact section.

The project combines a futuristic cyber-tech theme with a simple, user-friendly interface.

## 🚀 Project Overview

**ApexPro X1** is a smartphone product landing page designed to present product features and benefits in an attractive way. It uses a dark navy background, cyan highlights, magenta accents, and modern typography to create a futuristic visual experience.

The website is designed as a front-end web development mini-project for practising HTML structure, CSS styling, responsive layouts, and Tailwind CSS utilities.

## ✨ Features

- **Navigation Bar:** Quick links to different sections of the website.
- **Hero Section:** Introduces the ApexPro X1 smartphone with a product image and call-to-action buttons.
- **Powerful Features:** Highlights smartphone performance, battery life, and camera capabilities.
- **Benefits Section:** Explains the advantages of the product.
- **Customer Testimonials:** Displays sample customer reviews.
- **Pricing Section:** Presents the product price and a launch offer.
- **Contact Form:** Provides fields for name, email, and message.
- **Location Section:** Displays sample headquarters and retail location information.
- **Responsive Layout:** Uses Tailwind CSS responsive utilities to adapt the layout to different screen sizes.
- **Cyber-Tech Theme:** Uses a dark background, cyan and magenta accents, glowing effects, and modern fonts.
- **Smooth Scrolling:** Provides smooth navigation between page sections.

## 🛠️ Technologies Used

- **HTML5** – Structures the website content.
- **Tailwind CSS** – Provides utility classes for layout, spacing, typography, and responsiveness.
- **Custom CSS** – Controls the colour palette, typography, hover effects, gradients, and responsive styling.
- **Google Fonts** – Uses Space Grotesk and DM Mono for a modern interface.
- **Unsplash** – Supplies externally hosted product imagery.

## 💻 Getting Started

### Prerequisites

You will need:

- A computer with a modern web browser.
- Visual Studio Code (recommended).
- The Live Server extension for VS Code (recommended).
- An internet connection to load Tailwind CSS and Google Fonts from their CDNs.

### Installation and Setup

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `INDEX.html`.
4. If Live Server is installed, right-click the HTML file.
5. Select **Open with Live Server**.
6. View the website in your browser.

You can also open `INDEX.html` directly in a web browser, although Live Server makes development and testing more convenient.

## 📱 Responsive Design

The website uses Tailwind CSS breakpoints and responsive grid utilities to adjust the layout for different screen sizes.

- **Mobile:** Content is arranged in a single-column layout where appropriate.
- **Tablet:** Sections adapt to the available screen width.
- **Desktop:** Navigation and content sections use wider layouts for better readability.

Custom CSS media queries further adjust the hero section, heading size, and spacing on smaller screens.

## ⚙️ Customisation

You can customise the website by editing `INDEX.html`.

- **Colours:** Modify the CSS variables inside the `:root` selector.
- **Fonts:** Change the Google Fonts import and the `font-family` properties.
- **Product content:** Edit the hero heading, feature descriptions, benefits, and pricing.
- **Images:** Replace the image URLs with your preferred product images.
- **Navigation:** Update the anchor links and section IDs.
- **Layout:** Modify Tailwind CSS classes and custom CSS rules.
- **Branding:** Update the project name, logo text, and footer information.

## ⚠️ Current Limitations

- The contact form is a front-end form and does not send messages to a server.
- The Buy Now buttons are demonstration links and are not connected to a payment system.
- Product specifications, prices, testimonials, and location details are sample content for demonstration purposes.
- External images, fonts, and Tailwind CSS require an internet connection.
- The project does not currently include a database or backend.
